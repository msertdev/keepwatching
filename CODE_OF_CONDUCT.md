# Code of conduct

## Our standard

We are committed to a welcoming, safe, and constructive project. Be respectful, assume good intent, criticize ideas rather than people, and make room for contributors with different backgrounds and levels of experience.

Unacceptable behavior includes harassment, discrimination, sexualized language or attention, threats, sustained disruption, publishing private information, and any conduct that would reasonably make another participant feel unsafe.

## Project spaces

This standard applies in issues, pull requests, discussions, code review, community calls, and public spaces where someone is representing the project.

## Enforcement

Maintainers may edit or remove comments, close or lock threads, reject contributions, or temporarily or permanently restrict participation when behavior violates this standard. Enforcement decisions will consider context, impact, and patterns of behavior.

Report conduct concerns privately to the repository maintainers through GitHub. Security vulnerabilities should use the separate process in [SECURITY.md](./SECURITY.md). Reports will be handled as confidentially as practical.
